# Hound

## Overview

Hound is an information gathering tool developed by TechChip. It is designed to collect information from a web browser when a user opens a generated web page. Depending on browser permissions, it can also request access to the device's location.

> **Note:** I used this tool only in my personal lab environment on devices that I own or have permission to test.

---

# Purpose

This tool helped me understand:

- Browser information gathering
- Public IP detection
- Browser permissions
- GPS permission requests
- PHP local server
- Cloudflare Tunnel
- Localhost vs Public URL

---

# Features

- Browser Information
- Device Information
- Public IP
- ISP Details
- Approximate Location
- GPS Location (Requires Permission)
- Cloudflare Tunnel Support
